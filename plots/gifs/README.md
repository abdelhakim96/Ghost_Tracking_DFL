# Maneuver animations (3-axis emulation)

Animated GIFs of the multicopter+3-axis-gimbal emulating a fixed-wing aircraft
through aerobatic maneuvers. Generated by `utilities/animate_maneuver.m` from
`results/results_v3_<tag>.mat`.

**Left panel** — 3D scene: red STL fixed-wing flies the reference trajectory;
blue quad glyph tracks the same camera position with its own (banked/pitched)
body attitude; the green boresight triad is the gimbal camera frame
`q_M ⊗ q_G`, locked onto the fixed-wing attitude `q_A`.
**Right panel** — live geodesic camera-orientation error vs time (log scale).

| GIF | Maneuver | View mode |
|-----|----------|-----------|
| `loop.gif` | vertical loop | whole trajectory |
| `cuban8.gif` | Cuban-8 | whole trajectory |
| `immelmann.gif` | Immelmann turn | whole trajectory |
| `splits.gif` | Split-S | whole trajectory |
| `barrelroll.gif` | barrel roll | follow camera |
| `roll.gif` | axial roll | follow camera |
| `rollsoft.gif` | soft roll | follow camera |

## Regenerate

```matlab
addpath('utilities');
animate_maneuver('loop');                    % whole-trajectory view (default)
animate_maneuver('roll','mode','follow');    % vehicle close-up (best for rolls)
% options: 'nframes' (80), 'dpi' (96), 'delay' (0.06 s), 'mode' ('whole'|'follow')
```

`_*_check.png` files are throwaway single-frame previews and can be deleted.
