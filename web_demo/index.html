Ghost-Tracking DFL Demo

A fixed-wing aircraft you pilot; a multicopter+gimbal tracks it in real time.

What you're seeing

  • Left half — the camera POV from inside the fixed-wing cockpit.
  • Right half — the camera POV from the drone's gimbal-mounted camera.
  • When the controller works, both views are pixel-similar.
  • Bottom-right inset — external view of FW (transparent) + drone (solid) so you can see them coincide.
  • Bottom-left minimap — top-down trajectory traces, red = FW, blue = drone.

How to fly

↑ ↓Pitch up / down (elevator)
← →Roll left / right (aileron)
A DRudder left / right
W SThrust up / down
RReset simulation
PPause / resume

Tip: start with a gentle pitch-up to climb, then add a touch of aileron to roll. Watch the joystick gauge in the cockpit dashboard to see your stick position. The right-side bars show the DFL controller commanding the drone to match.
